# Как открыть проект

## Поиграть на Windows

Распакуй весь архив AlemAI_Windows_Portable.zip и открой AlemAITrainer.exe. Папка _internal должна остаться рядом с приложением. Python устанавливать не нужно. При первом открытии подожди загрузку моделей, затем нажми Space.

WASD - движение, мышь или стрелки - обзор. Подойди к бирюзовому терминалу и нажми E. Клавиша 1 принимает рекомендацию AI, 2 выбирает другой доступный выход, 3 показывает объяснение алгоритмов. Q закрывает окно. Иди по бирюзовой линии к выбранной лестнице и нажми E.

На втором этаже в сценарии smoke после выбора маршрута нажми U: выбранный выход станет недоступен, а система перестроит путь. F5 меняет сценарий, R начинает заново, C загружает сохранение. Escape отпускает мышь. После выхода на площадь идут исходные титры и благодарность Dilnura Ali; Enter открывает результаты. M отключает звук и речь. Результаты сохраняются в user_data.

## Редактировать или запустить на другом компьютере

Этот архив содержит исходники. Нужен Python 3.10 или новее. На Windows запускай START_WINDOWS.cmd, на macOS/Linux - sh start_macos_linux.sh. Первый запуск устанавливает Panda3D, поэтому нужен интернет. Доработанная версия проверена на Windows; запуск на macOS/Linux вам ещё нужно проверить на своих компьютерах.

Исходный режим с вопросами сохранён: python main.py --legacy. Новый тренажёр запускается обычной командой python main.py.
